# Agent 生命周期

- 生成由显式「模型 → 工具 → 模型」循环管理，关闭框架内部自动执行工具。
- 每个会话最多一个活动回合；限制全局并发、总时长、输出和工具调用次数。
- requestId 唯一，每次重试用新 ID。取消按 requestId 和 conversationId 精确匹配。
- SSE 固定信封为 type / requestId / conversationId / data；start 开始，done 或 error 结束。
- 取消/超时先停止上游订阅和工作任务，再处理网络收尾；终态最多保存一次。
- 只把成功完成的回合放进模型历史，工具调用与工具结果成对保存，不截断单个回合。
- 失败和取消可保存部分回答用于界面恢复，但不作为成功上下文继续发送。
- 工具输入必须有界并经过校验；不执行模型提供的代码、SQL 或任意表达式。
- SQLite 保存会话、回合和工具结果；进程重启后将遗留 running 回合标为中断。
- 测试使用临时 SQLite 和本地 OpenAI 兼容模拟服务，通过真实 Spring AI 适配器验证协议；不需要真实 Key。
