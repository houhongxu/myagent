# 页面与异步开发

- 页面专属组件就近组织，根组件只挂载页面；复用 Ant Design / AntDX，避免另建组件体系。
- 页面负责展示、表单和确认交互；Hook 负责会话状态、请求与取消。当前单页无需额外状态管理依赖。
- 请求处理中避免重复提交；加载、空数据、失败和取消都提供可见状态。
- 删除会话需确认；弹窗保存成功后关闭，失败时保留输入。
- 旧请求不能覆盖新会话；卸载或切换时清理流、定时器和取消请求。
- POST SSE 必须校验 requestId / conversationId，识别 start 和终态；异常断流不当作成功，不自动重放生成请求。
- Markdown 默认转义 HTML；不自动加载模型给出的远程图片，不直接执行模型输出。
- 当前界面使用中文，无需双语资源或国际化框架；API code 与工具名保持稳定。
- 测试位于 `test/`，覆盖协议边界和状态变化。验证页面时使用本地模拟服务及隔离数据，不自动请求付费模型。
- TS 保持 strict，避免 any。结构修改运行 `pnpm build` 和相关现有测试；交互修改还需检查浏览器表现。
